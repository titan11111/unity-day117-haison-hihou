# Day 117 仕様 — 廃村の蒼き秘宝（サウンドノベル）

> 2026-11-23 改訂。正とする指示＝タイタンのChatGPT依頼文（attachment）。
> 「8人のキャラをベースに、廃墟の村を巡るお宝ハンターのサウンドノベル。骸骨・トラップなどの危険をかいくぐり、世界一大きい宝石にたどり着くのがゴール。表情・切り抜き・キャラ設定が大事」
> haison_onsen_hunter_complete.html は「画面UI・選択肢・セーブ・読み上げ」の試作として流用し、物語（老婆・地下集落・秘湯ゴール）は採用しない。

- 遊びの核：サウンドノベル。文章を読み進め、要所の選択肢と謎解きで罠・骸骨・仕掛けを突破し、村の地下に眠る世界最大の宝石「龍神の珠」を見つける。どのルートでも宝石の発見は必ず体験できる。
- 舞台：山奥の廃村（かつての温泉村）。100年前に村人が一夜で消えた。崩れた家・骸骨の酒場・鳴らない鐘楼・地下迷宮・封印の扉・蒼く光る源泉の宝物庫。
- 怖さの方向：不気味さ中心。骸骨は出すが残酷描写はしない。
- 見た目：アニメ調立ち絵（三面図の正面を切り抜き）＋暗い廃村背景。会話中は話者を明るく、非話者を暗く。通常2人・重要場面3人。
- 登場人物（絵の役どころに合わせる。名前は設定画の1枚に統一）：
  | No | 名前 | 立ち絵 | 物語での役 |
  |---|---|---|---|
  | 01 | ユウマ | カード少年 | 主人公。トレジャーハンター見習い。祖父の形見の巻物を持つ |
  | 02 | ガンツ | 採掘師 | 罠・崩落を見抜く。力仕事。過去にこの村へ来た形跡 |
  | 03 | レオン | 投資家 | 情報屋。古い地図と宝の噂を持ち込んだ張本人 |

- 第4章だけ一人称の3Dダンジョン（ウィザードリィ風のマス移動）に切り替える。詳細は設定集4.5
- 構成：全6章（1 誰もいない村／2 骸骨の酒場／3 鳴らない鐘楼／4 地下迷宮／5 封印された扉／6 世界最大の宝石）。選択肢20〜30、謎解き8〜10、プレイ60〜90分。
- 罠と危険：落とし穴・仕掛け扉・動く石像・崩落・毒の湯気など。失敗は即死にせず、ケガ／仲間の信頼低下／遠回りで返す（ゲームオーバー無し、直前から選び直し可）。
- エンディング3種：①宝石を持ち帰る ②発見したが封印を守る ③村の秘密を解いたうえで持ち帰る（真END）。
- 対象端末・公開：PCブラウザ（16:9）＋スマホ縦。Unity WebGL → Cloudflare Pages（初回作成時はタイタンOK）。
- 操作：タップ／クリックで文送り・選択。PCはSpace/Enter送り、数字キー選択。オート・スキップ・履歴。
- セーブ：オートセーブ＋任意セーブ3枠。END回収をタイトルに表示。
- 音：BGM（廃村・緊迫・謎解き・宝物庫）、SE、VOICEVOXで主要セリフに声。
- 素材の扱い：
  - 立ち絵の元＝ChatGPT 画像1〜8（三面図・透過）。正面を切り抜いて使う。顔アップ＝画像9（ユウマ）・10（エリス）
  - 表情：まず設定画の2表情＋顔アップで「通常・笑顔」。不足（驚き・恐怖・怒り・思案）は元絵に合わせて追加生成。顔と髪型は変えない
  - 背景：Codexで生成（人物・文字なし）
- 対象外：3D化、ホラーの残酷表現、01_元資料（和メイド衣装・駅レンタルCM）、HPテスト.html
- 受入条件：3つのENDすべてに到達（自動テスト）／Consoleエラー0／PC横・スマホ縦で文字のはみ出しや重なりなし（スクショ）／セーブ・ロード・再開OK／公開URLが200でSHA一致
- 技術：Unity 6000.3.26f1 / C# / uGUI＋FitBox。シナリオはJSON（章・行・話者・表情・立ち位置・選択肢・フラグ）
